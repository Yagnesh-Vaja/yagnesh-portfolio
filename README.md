# Yagnesh Vaja — Portfolio

Personal portfolio site for Yagnesh Vaja, frontend developer (React Native, Expo, TypeScript, React, Astro, Tailwind CSS) based in Mumbai.

It is a single static page (`index.html`) with no build step: HTML, CSS and vanilla JavaScript, with fonts from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Hosted on Vercel as a static site. Every push to `main` triggers a new deployment.
